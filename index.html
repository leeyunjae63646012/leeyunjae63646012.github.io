사용방법

HTML 제작기를 처음 쓰시는 분들을 위한 단계별 안내입니다.

1

에디터에 코드 입력

홈 화면의 에디터 창에 원하는 HTML 태그를 입력하세요. 여는 태그를 완성하면(예: <div>) 닫는 태그가 자동으로 붙습니다.

2

필요 없는 닫는 태그 삭제

자동으로 생긴 닫는 태그가 필요 없다면 지워도 됩니다. 지운 뒤에는 다시 저절로 생기지 않으니 편하게 편집하세요.

3

새 태그는 다시 자동 완성

다른 자리에서 다시 <태그명> 형태로 입력하면 그 태그는 또 자동으로 닫힙니다. 삭제와 재입력이 서로 영향을 주지 않아요.

4

파일 이름 정하기

에디터 상단의 파일 이름 칸에 원하는 이름을 적어주세요. 확장자는 신경 쓰지 않아도 저장할 때 자동으로 .html이 붙습니다.

5

다운로드 버튼 클릭

에디터 오른쪽 위의 다운로드 버튼을 누르면 작성한 코드가 .html 파일로 즉시 저장됩니다.

6

처음부터 다시 시작

초기화 버튼을 누르면 에디터가 기본 템플릿으로 돌아갑니다. 실수했을 때 편하게 다시 시작할 수 있어요.

자동 닫기가 적용되지 않는 경우

<!DOCTYPE html>과 같은 선언문, </div>처럼 이미 닫는 태그, <br/>처럼 스스로 닫히는 태그, 그리고 br·img·input·meta·link·hr 등 홑닫힘(void) 태그는 자동으로 닫는 태그를 만들지 않습니다.
